# 管理员 HTML 交互原型

沿用已确认的浅色报名管理主页。此目录是纯前端原型，不调用真实数据库、SSO、邮件或图片服务。演示修改仅保存在当前浏览器的本地存储中。

## 入口

- [报名管理](admin-registration.html)：搜索、筛选、分页、CSV 导出、报名详情、修改回执、邮件预览与确认、发送记录。
- [荣誉墙](admin-honors.html)：列表、详情、图片预览、新增、编辑、删除确认、1～9 张图片选择与排序。
- [报名详情直达](admin-registration.html?panel=detail&id=1)
- [修改回执直达](admin-registration.html?panel=edit&id=4)
- [邮件预览直达](admin-registration.html?panel=mail&id=1)
- [失败邮件记录直达](admin-registration.html?panel=history&id=6)

## 体验说明

- 点击行内“查看”“修改”“邮件预览”打开对应面板；详情中的“邮件记录”显示历史。
- 不到场时不提供到场领取；选择邮寄时，邮寄地址必填。
- 修改回执不自动发信。确认前需勾选核对项；确认后显示任务已登记，演示不会变成真实投递。
- 同版本处理中任务会复用；历史版本的记录保留。
- 荣誉仅包含标题、人员文本、1～9 张图片。可选本机图片，也可用“使用示例图片”体验排序。
- 图片可拖动排序，或使用左右箭头；第一张为封面。预览图均为原型示例。
- 修改表单有未保存关闭确认，删除荣誉有二次确认。
- 原型不提供自建登录页；账户入口只演示退出确认。
- 公开访客页面与回忆墙投稿页面仍暂缓。
- 使用同一个本机 HTTP 地址可跨页面保留演示修改；清除该站点本地存储即可恢复初始数据。

使用 Python 启动静态服务：
    python -m http.server 5174 --bind 127.0.0.1 --directory prototypes
