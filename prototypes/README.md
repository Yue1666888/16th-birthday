# 管理员 HTML 交互原型

沿用已确认的浅色报名管理主页。此目录是纯前端原型，不调用真实数据库、SSO、邮件或图片服务。演示修改仅保存在当前浏览器的本地存储中。

## 入口

- [报名管理](admin-registration.html)：搜索、筛选、分页、CSV 导出、报名详情、修改回执、邮件管理快捷入口。
- [邮件管理](admin-mail.html)：单发逐人编辑主题与正文，群发选择报名者、编辑模板、插入变量、逐人预览、确认批次、查看正文快照与发送记录。
- [荣誉墙](admin-honors.html)：列表、详情、图片预览、新增、编辑、删除确认、1～9 张图片选择与排序。
- [报名详情直达](admin-registration.html?panel=detail&id=1)
- [修改回执直达](admin-registration.html?panel=edit&id=4)
- [邮件预览直达](admin-mail.html?mode=single&id=1)
- [失败邮件记录直达](admin-mail.html?view=history&id=6)

## 体验说明

- 点击行内“查看”“修改”打开对应面板；“写邮件”及详情中的“邮件记录”跳转到独立邮件管理。
- 不到场时不提供到场领取；选择邮寄时，邮寄地址必填。
- 修改回执不自动发信。确认前需勾选核对项；确认后显示任务已登记，演示不会变成真实投递。
- 新邮件管理允许管理员编辑不同主题与正文；每次明确确认形成独立演示发送批次。单发草稿按报名者分别保存，群发模板单独保存。历史记录冻结确认时的邮件正文。
- 荣誉仅包含标题、人员文本、1～9 张图片。可选本机图片，也可用“使用示例图片”体验排序。
- 图片可拖动排序，或使用左右箭头；第一张为封面。预览图均为原型示例。
- 修改表单有未保存关闭确认，删除荣誉有二次确认。
- 原型不提供自建登录页；账户入口只演示退出确认。
- 公开访客页面与回忆墙投稿页面仍暂缓。
- 使用同一个本机 HTTP 地址可跨页面保留演示修改；清除该站点本地存储即可恢复初始数据。

使用 Python 启动静态服务：
    python -m http.server 5174 --bind 127.0.0.1 --directory prototypes

## 邮件管理更新

- 单发模式：选择一位报名者，自定义主题、正文；每位报名者保留各自草稿。
- 群发模式：按姓名、手机号、邮箱搜索，按到场状态和礼物方式筛选；可勾选个人或全选当前筛选结果，切换筛选保留已选项。
- 模板变量：{{name}} 姓名、{{attendance}} 是否到场、{{giftChoice}} 礼物方式、{{id}} 回执编号；主题和正文均可插入。未知变量、未闭合变量会阻止确认。
- 群发预览：可切换每位收件人，查看实际替换后的内容；每位收件人单独生成邮件，不使用抄送名单。
- 确认发送：显示完整名单和数量，勾选核对后才能登记。登记结果显示任务处理中，不伪装成已经投递。
- 发送记录：集中展示单发、群发和原有回执通知；支持姓名、邮箱、主题搜索及状态筛选，保存发送时的主题和正文快照。
- 草稿与模拟发送记录仅存在当前浏览器本地。不会调用后端或真实邮件服务。
- 当前 Java 后端仍采用原固定模板确认接口；自定义邮件、群发批次和模板校验属于后续需要扩充的后端功能。本次只更新 HTML 原型。
