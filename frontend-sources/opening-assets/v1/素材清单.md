# 开场动画素材清单 v1

日期：2026-11-22。用途：配合根目录[开场动画分镜与对白脚本](../../../开场动画分镜与对白脚本.md)，本目录保留素材母版；网页交付副本已接入播放器，见[实现与验收](../../../开场动画实现与验收.md)。

## 1. 交付结构

```text
v1/
├── desktop/                    # 6张提供的横版场景原图
├── mobile/                     # 6张按原画重排生成的竖版场景
├── sprites/                    # 2张原始气球 + 5张补充插画
├── photos/                     # 6张选用的真实照片
├── assets-manifest.json        # 25项素材：来源编号、尺寸、哈希、生成提示词
├── opening-timeline.v1.json    # 11幕、109秒的脚本时间轴
└── 素材清单.md
```

共有25张选用素材：6张原有电脑场景、6张新生成手机场景、2张原始气球、5张补充生成图、6张真实照片。其中**11张为AI生成或参考图编辑生成**。所有真实照片均为原样复制；没有生成人物替代照片。电脑原画直接复用提供的二维设计，手机重新安排竖屏构图。

生成使用内置 `imagegen`，没有调用本机ComfyUI。每张图的最终英文提示词、参考文件名和生成文件编号保存在[assets-manifest.json](assets-manifest.json)的 `prompt/reference/generatedBasename` 字段中。该文件不保存原资料中的临时授权下载地址。

`frontend-sources/opening-reference-cache/` 是原资料图片的本地参考缓存，不是线上资源目录；`opening-drafts/` 是未选用的探索稿，均不属于本清单的25项。原稿的MP4只有文件名，没有可用视频文件；本次没有生成视频或音频。

## 3. 双端对应和图层使用

| 镜头 | 电脑/手机主背景 | 附加图层 |
| --- | --- | --- |
| 道路 | D01 / M01 | 主气球B01，字幕DOM |
| 登船 | D02 / M02 | 直接用完整插画，不额外叠一套人脸 |
| 起飞和云页 | D03 / M03 | B01、云S03、鸟S02、六张真实照片、DOM时间签 |
| 群飞遮挡 | D03 / M03 | 六球图集S05、B02或前景备选S01、实色遮罩 |
| 门口 | D04 / M04 | 手机空门牌叠115，横版已有门牌不重复叠 |
| 暗室灯 | D05 / M05 | 局部光层、极少尘粒、点灯按钮 |
| 庆祝 | D06 / M06 | 少量纸屑、字幕 |
| 接信/打开 | D06/M06 → 暖白底 | CSS信封、S04信纸、DOM欢迎语 |

电脑图约16:9，手机大多数约9:16，门景两张为1:2；显示时保持原始比例。平板与超宽屏允许同色背景延展。原始横版门景和生日群像有烘焙文字，竖版门牌/条幅为空白，需要实施时叠精确文字；两端表达相同，不要求烘焙字形像素一致。

闭门/开门的背景、道具形状存在细节差异，第一版以门区域蒙板溶解和推近衔接，不能把两张静帧称作连续推门视频。竖版原图更大不代表适合不压缩地下载。

## 4. 透明精灵定位和图集

原始透明气球包含大量空白画布，不能把整个PNG盒子当作气球主体去设置画面中心。以下是图中Alpha非零的包围盒，格式为左、上、右、下（右/下不含），用于实施时的Canvas sourceRect或包装容器坐标换算，不代表本次修改了原图。

- B01：画布1280×714，Alpha非零范围 `(193, 27, 498, 520)`；主体Alpha>128范围 `(197, 30, 495, 519)`。
- B02：画布1280×714，Alpha非零范围 `(506, 93, 770, 478)`；主体Alpha>128范围 `(510, 95, 768, 475)`。

不要重复生成或用程序改画B01里的脸。稳定飞行直接复用B01。S01的两次生成仍有柔光，不宣称为硬边干净抠图，只用于低时长前景掠镜；若合成后显脏，直接改用B02并用不透明遮罩完成换场。

S02/S03也有细小半透明边缘，在浅青天空、较小显示尺寸下使用，实施时仍须检查实际合成效果；不应移入深色加载页放大。S05远景优先缩小，必要时省略，不影响剧情。

S05图集实际1536×1024，单元512×512，顺序：

| 行/列 | 1 | 2 | 3 |
| --- | --- | --- | --- |
| 第1行 | 珊瑚橙 | 浅蓝 | 浅黄 |
| 第2行 | 鼠尾草绿 | 粉玫瑰 | 浅青 |

可用 `background-size: 300% 200%` 配合位置选择单元，或Canvas按512正方形源区域绘制。外侧透明区域属于单元留白，画面大小应按可见球体估算。

## 5. 真实照片的使用

P01/P02来自原设计中的两张成员合照；P03/P09/P11/P18来自照片资料，按会议记录、技术培训、团建聚餐、开放日分组。该分类不是图像识别得出的个人身份，也不确认具体拍摄日期或成果。

照片默认contain并露出完整人物，文字在照片外。P01/P02只有400px宽，优先小相框；没有更高清源图前，不用AI重绘或扩充真实面孔。P18是4096px宽母版，不需按原尺寸下载到手机。

原资料中的照片14为MPO封装，本次没有选用，也没有把它改扩展名冒充浏览器可用JPEG。

## 6. 实施时的资源处理

这些是可审阅的PNG/JPG母版，不能把整个目录放入首屏预加载。现已另导出web/public/opening的25张WebP交付副本（合计约1.47MiB），播放器按电脑/手机资源清单选择加载；照片原件和本次母版保留。

建议目标（待真实导出和验收，不是已达成数据）：背景单张约150–400KB，首段启动图像总量尽量控制在1.5MB内；照片按实际显示宽度提供1×/2×尺寸。包含透明度的精灵不得误用无Alpha格式。压缩后逐张检查脸部、文字边缘、门框与透明外缘。

信纸S04没有活动日期、地点或表单文字；社团标识使用现有项目图标资源，不依靠AI生成的文字标。加载界面、门牌、欢迎语、字幕和按钮继续用DOM/CSS绘制。
